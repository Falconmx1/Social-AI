## 🧠 ¿Qué es Social AI?
Herramienta de **ingeniería social potenciada por IA** que automatiza:
- 📇 **OSINT** de personas/empresas (redes, emails, empleados, estructura)
- 🎣 **Generación de pretextos y phishing controlado** (solo entornos autorizados)
- 🧪 **Simulación de ataques** (vishing, SMS, correos, USB dropping)
- 📊 **Reportes de riesgo humano** (qué empleados son más vulnerables)

**NO es un script de script kiddie, es una suite profesional para auditores.**
